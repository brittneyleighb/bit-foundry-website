WHAT YOU SHOULD LEAVE WITH

Not facts. A causal model.

The goal is to give you enough structure that later concepts like virtual memory, processes, system calls, and kernels have somewhere to attach.

You should understand

  • the difference between source code and machine instructions
  • what compilation actually produces
  • what a process is at a basic level
  • why variables have addresses
  • what pointers represent
  • where the operating system fits into execution

Stage 01 checkpoint

Take a tiny C program and explain the journey:

  • source code is compiled
  • an executable is produced
  • the OS creates a process
  • code and data are placed into memory
  • the CPU executes instructions
  • the kernel mediates privileged operations

Start with the abstraction stack.
