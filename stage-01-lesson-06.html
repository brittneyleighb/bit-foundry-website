01 / REBUILD THE MODEL

Close the diagram in your head and rebuild it.

Imagine a friend asks: “What actually happens when you compile and run a tiny C program?” Explain it without using jargon as decoration. Every term should represent a causal step.

CHALLENGE / FREE RESPONSENO PERFECT WORDING
Explain the journey:

You have a file named hello.c. You compile it, run the resulting executable, and the program prints text to the screen. What has to happen between those events?
SAVED LOCALLY ✓
WHAT GOOD EXPLANATIONS DO

They connect events. Instead of saying “the kernel is involved,” say what role the operating system has in creating a process, providing memory, and mediating privileged operations.

05 / STAGE COMPLETE

Foundations is not mastery. It is a map you can now walk.

You are ready for Stage 02 when you can:
  • trace a basic program from source to execution;
  • reason about values, addresses, pointers, and memory at a beginner systems level;
  • separate executable files from running processes;
  • use compilation and debugging tools as evidence-gathering instruments;
  • ask which layer likely caused a behavior instead of treating the computer as one opaque box.

Complete Stage 01: Foundations.

Mark the stage complete when your explanation feels causal rather than memorized. Stage 02 will move into processes, files, system calls, signals, and the interfaces programs use to talk to the operating system.
